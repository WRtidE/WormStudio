# WormStudio v1.0.1

发布日期：2026-11-17。本次为 Mac 启动与显示修订，跟踪和测量算法保持不变。

## 下载和安装

- `WormStudio-Mac-arm64.zip`：Apple 芯片、macOS 14+ 离线桌面版，包含 Python、Electron、依赖及模型。
- `WormStudio-v1.0.1-source.zip`：对应源码及逐文件校验清单，供开发使用。
- `SHA256SUMS.txt`：上述两个文件的 SHA-256。

解压 Mac ZIP，将 WormStudio.app 拖入“应用程序”，双击后选择“准备并打开”。建议预留至少 12 GB 空间；实验视频另计。应用尚未公证，首次打开方式见包内“先读我.txt”。更新保留已有工作区及结果，进行中的分析应先完成。

Windows 本次没有重新构建，继续使用 [v1.0.0 Windows 安装包](https://github.com/WRtidE/WormStudio/releases/download/v1.0.0/WormStudio-Windows-x64.exe)。

## 修复

1. Finder 在 Rosetta 环境启动脚本应用时自动切回 arm64，避免 Apple 芯片电脑被错误判为不支持。
2. 启动提示使用应用图标；Dock 图标增加透明留白，修正视觉尺寸偏大。
3. 通道计数标签去掉继承的描边，恢复文字可读性；刻度按画面宽度避让，并在窗口调整后重绘。

## 本机实测范围

使用一段 3200 × 2200、12 fps、177 帧的视频测试三个培养槽，共生成 531 行逐帧结果。视频及原始分析数据不随公开发布上传。

| 检查项目 | 结果与范围 |
| --- | --- |
| 导入、500 μm 标定、ROI、分割和人工头点 | 已通过实际桌面流程验证 |
| 完整分析 | 三个培养槽各完成 177 帧；一个通过桌面/MPS 新标注处理，另两个用同版本源码在 CPU 上复用已有掩膜与标注处理 |
| 结果完整性 | 三槽各有 177 帧掩膜；有效姿态分别为 175、177、177 帧；连续 CSV 无重复帧 |
| 结果查看与导出 | 3 个 H.264 结果视频均可解码 177 帧；桌面逐帧定位、详情、CSV 导出及历史恢复已验证 |
| 任务控制 | 处理预览暂停/恢复已验证；并行处理触发内存保护后，保留标注并顺序重试完成 |
| 既有回归测试 | 49 项通过：19 项前端逻辑、23 项指标/通道、7 项任务队列 |

以上是功能与数据完整性验证，未使用逐帧人工真值计算分割、姿态或头尾准确率。

## 已知限制

- 通道计数适用于具有明确上下边界的通道画面。此次圆形柱阵培养槽样本不满足该几何假设，自动边界排除了部分实际轨迹，计数为 0，另有 8 帧被跳过；此结果不能作为通道计数准确性通过的依据。使用时应重新选取通道 ROI 并复核边界与越线记录。
- 当前表型导出帧号从 0 开始，通道计数从 1 开始；交叉核对时相差 1。
- 同时进行多个 SAM2 任务会增加内存压力，内存较少的 Mac 建议通过队列顺序处理。
- 自动头尾和低质量姿态仍需结合逐帧质量记录复核。
