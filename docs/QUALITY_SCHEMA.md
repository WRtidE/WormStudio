# 质量与测量规则

实现版本 `wormstudio-quality-v2`。源帧、掩膜、姿态、身份、头尾、尺度分别记录有效性、状态、原因与证据。自动通过不等于独立生物真值。

|结果|要求|
|---|---|
|匿名轮廓面积|源帧、掩膜、尺度或像素模式|
|正式体长、体宽|源帧、掩膜、姿态、身份、尺度或像素模式|
|体积估算|正式姿态条件及简单拓扑等体积条件|
|质心运动|源帧、掩膜、身份、时间与尺度或像素模式|
|正式头部角度|可靠姿态、身份、时间和真实人工头端确认|

缺失值为CSV空值、JSON `null`、界面“—”；不把缺失速度当作零。跨身份、排除帧和缺口不强行连成连续运动。没有标定时输出px、px/s及相应像素面积/体积估算。

## 实线与虚线

只有正式姿态通过、显示来源为`formal`时画白色实线。有当前图像支持、但正式几何或身份条件不通过时画橙色虚线；没有可靠可显示几何则不画线。

|几何检查|当前要求|
|---|---|
|正式骨架在掩膜内的顶点比例|≥97%|
|体长|参考值的65%–135%，含边界|
|局部折返|约5%体长内净累计转角≤150°|
|补显示候选初始密集掩膜支持|≥97%|
|补显示修整后密集掩膜支持|≥99.9%|
|补显示最短曲线|≥5px|
|补显示边界顶点修正距离|≤3px|

这些不是唯一接受条件；自接触路径不唯一、上游姿态求解拒绝、分割异常或身份待复核也会导致虚线。掩膜支持不保证掩膜或解剖拓扑正确。虚线不进入正式姿态测量。头尾未确认本身不会使身体变成虚线。

## 头尾

新任务默认`taper_seed`：人工头点优先，否则使用起始可靠帧的端部渐细证据；`manual_seed`只使用人工种子。旧`twardis`综合模式和`manual_only`保留。短缺口≤0.25秒且整条骨架关联合格才传播；跨短缺口的人工方向仅作为候选，不扩大人工确认范围。

画面固定H/T标签不改变上述语义。自动头尾、固定点序和TAP点在虫体内都不是解剖正确率。需要独立真实标注才能评估错向率、翻转率和弃判率。
