# 质量与测量规则

实现版本 `wormstudio-quality-v2`。源帧、掩膜、姿态、身份、头尾、尺度分别记录有效性、状态、原因与证据。自动通过不等于独立生物真值。

|结果|要求|
|---|---|
|匿名轮廓面积|源帧、掩膜、尺度或像素模式|
|正式体长|源帧、掩膜、姿态、身份、尺度或像素模式；身体序列的两端须可观察|
|正式体宽|正式姿态条件；身体序列须为简单拓扑，接触轮廓不用于正式宽度|
|体积估算|正式姿态条件及简单拓扑等体积条件|
|质心运动|源帧、掩膜、身份、时间与尺度或像素模式|
|正式头部角度|可靠姿态、身份、时间和真实人工头端确认|

缺失值为CSV空值、JSON `null`、界面“—”；不把缺失速度当作零。跨身份、排除帧和缺口不强行连成连续运动。没有标定时输出px、px/s及相应像素面积/体积估算。

身体序列的隐藏端点长度写入 `length_estimate_um`（像素模式为 `length_estimate_px`），不进入正式体长和依赖该体长的逐帧比例。`length_measurement_status`、`width_measurement_status` 记录缺失原因。几何、图像运动与规则分不能代替真值置信度。无法建立相邻身体对应时分段，不跨断点求速度或传播人工确认。

## 中线显示与复核

测量中线和有掩膜支持的复核中线均画实线。画面用 REVIEW 标记需要复核的姿态，逐帧数据保留显示来源和测量状态。

|几何检查|当前要求|
|---|---|
|正式骨架在掩膜内的顶点比例|≥97%|
|体长|参考值的65%–135%，含边界|
|局部折返|约5%体长内净累计转角≤150°|
|补显示候选初始密集掩膜支持|≥97%|
|补显示修整后密集掩膜支持|≥99.9%|
|补显示最短曲线|≥5px|
|补显示边界顶点修正距离|≤3px|

单个绕柱交叉区间无法建立连续对应时，程序会用区间两侧的清晰中线及每一帧的掩膜拟合整段展示路径，比较体长、弯曲、绕柱方向和相邻帧整条中线的移动。人工头端可沿连续且能双向匹配的端点显示为 H?。在匹配出现歧义的交界处显示 A/B。正式姿态测量使用通过质量检查的帧。

## 头尾

新任务默认`taper_seed`：人工头点优先，否则使用起始可靠帧的端部渐细证据；`manual_seed`只使用人工种子。旧`twardis`综合模式和`manual_only`保留。短缺口≤0.25秒且整条骨架关联合格才传播；跨短缺口的人工方向仅作为候选，不扩大人工确认范围。

画面固定H/T标签不改变上述语义。自动头尾、固定点序和TAP点在虫体内都不是解剖正确率。需要独立真实标注才能评估错向率、翻转率和弃判率。
