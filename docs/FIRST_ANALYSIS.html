完成你的第一次线虫分析

适用 Windows 64 位。已附运行环境与模型，不需要安装 Python。请先将整个文件夹放在有写入权限的本地磁盘，保留所有子目录。

  1. 双击“启动软件.bat”。有可用 NVIDIA GPU 时自动加速，否则使用 CPU。浏览器会自动打开，请保留启动窗口。
  2. 第一次练习：在左侧导入 examples/practice.avi。这是人工生成的 5 帧练习视频，用来熟悉操作，不是生物准确率验证数据。
  3. 选择视频开始标注，选择完整画面和像素单位。在深色虫体内部添加正点，必要时在背景添加负点或涂画修正；核对轮廓后点击“确认虫体”。练习图像没有真实解剖头部，不必确认头端。
  4. 点击“确认并开始”，等待分割、时序跟踪、指标和导出完成。CPU 可能明显更慢，长视频建议先裁剪短片试运行。不要将等待误认为失败。
  5. 进入结果页，查看轮廓和骨架。虚线或缺失指标需要复核。真实样本如需头部指标，请人工确认头端；物理长度需要本次拍摄的真实标尺。
  6. 在导出区保存视频、逐帧指标和汇总。结果还保存在 app/outputs。关闭后再次启动，在历史任务中打开结果。

遇到问题

GPU 不可用或显存不足：关闭软件，双击“使用CPU启动.bat”，重新开始任务。CPU 和 GPU 采用相同模型，浮点结果可能略有差异。

浏览器未打开：复制启动窗口显示的本地网址。启动失败：将 logs 中本次日志交给维护人员。请勿单独移动 runtime 或 app。

备份：保留整个软件目录，尤其 app/outputs、app/input_videos 和 app/config 中的本机记录。更新时将新版放在新目录，先保留旧版和结果。

一次分析多个视频

  1. 从文件列表依次把视频拖到中央预览区，检查画面上方的顺序，然后点“开始顺序标定”。也可以一次导入多个视频，直接按导入顺序标定。
  2. 逐个视频选分析区域和尺寸单位，点选并确认虫体，再点“确认虫体并标定下一个”。最后一个视频点“确认虫体并开始顺序处理”。
  3. 在预览区右侧查看每个任务的状态和结果。单个任务失败后，队列会继续处理后续视频。停止或重启后，点“继续待处理任务”可以接着运行。
