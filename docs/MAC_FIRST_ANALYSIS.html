在 Mac 完成第一次分析

适用于 Apple 芯片 Mac。请使用维护者已完成实际视频验收的完整运行包；单独的源码包不能双击使用。

  1. 将整个目录放到有写入权限的最终位置，保留 app、runtime 和 examples。
  2. 双击“启动软件.command”。浏览器自动打开，保留终端窗口。默认 CPU，不需要安装 Python。
  3. 导入 examples/practice.avi，选择完整画面和像素单位，在深色虫体内点选并核对轮廓，点击确认虫体，再确认并开始。
  4. 等待分析完成。CPU 可能较慢。练习视频是合成图像，没有真实解剖头部，不需要确认头端。
  5. 在结果页复核骨架和质量提示，导出视频、逐帧指标和汇总。重新启动后可从历史任务打开。

真实视频的物理单位需实测标尺；头部指标需人工确认头端。虚线及缺失值需要复核。

“试验性Metal加速.command”仅供实机验证。如报错，请关闭后重新使用普通启动入口。

分析结果位于 app/outputs，导入视频位于 app/input_videos，日志位于 logs。备份整个目录。启动失败时把本次日志交给维护人员。

一次分析多个视频

  1. 从文件列表依次把视频拖到中央预览区，检查画面上方的顺序，然后点“开始顺序标定”。也可以一次导入多个视频，直接按导入顺序标定。
  2. 逐个视频选分析区域和尺寸单位，点选并确认虫体，再点“确认虫体并标定下一个”。最后一个视频点“确认虫体并开始顺序处理”。
  3. 在预览区右侧查看每个任务的状态和结果。单个任务失败后，队列会继续处理后续视频。停止或重启后，点“继续待处理任务”可以接着运行。
