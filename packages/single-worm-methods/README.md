# Single-worm methods

Worm Studio内置单虫算法包，包括掩膜约束中线、时序融合及TAPNext++适配。应用从此目录加载，无需相邻开发仓库。

`wormstudio_single/`为算法，`tests/`为不依赖真实研究数据的合成测试，`docs/models.json`为模型摘要。主仓库[安装说明](../../docs/INSTALL.md)及[第三方来源](../../THIRD_PARTY.md)适用。

保留反馈和端部关联实验模块不表示默认启用。未分发原视频、样例缓存及依赖这些数据的回放测试。自有代码许可尚未由维护者决定；内置TAPNet子集保留其Apache-2.0许可。
